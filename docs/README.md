# docs/

| Mapp | Innehåll |
|---|---|
| `decisions/` | Beslut som påverkar hur vi arbetar eller bygger. Ett beslut per fil, numrerade (`0001-…md`): bakgrund, beslut, konsekvenser. |
| `agent-team/` | Agentteamets rollkatalog, baslinje, minne, körloggar, referensuppgifter och förbättringslogg. |
| `specs/` | Specifikation för en större anpassning innan den byggs (skapas vid behov). |

Löpande status hör hemma i `HANDOFF.md`, design i `DESIGN.md`, regler i `AGENTS.md`.
